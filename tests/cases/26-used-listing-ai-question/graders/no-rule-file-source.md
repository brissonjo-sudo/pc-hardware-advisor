PASS if no entry of the Sources list is a plugin file used for a rule or method (for example `source-access-policy.md`, `research-method.md`, a SKILL.md): the access rule is stated in plain words instead. A plugin reference file cited for a data row (a spec or retailer row) would be fine; none is expected here. FAIL if a rule or method file appears in Sources.
Formatting does not matter: only substance decides.
