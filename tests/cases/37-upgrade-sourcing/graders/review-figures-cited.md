FAIL if a frame rate, a performance percentage, or a power, length or connector figure taken from a review or a maker's page is stated as a fact with no [n] citation in the same sentence, or with an [n] that has no URL in the Sources list. PASS if every such figure is cited that way, or is placed under Not verified.

These count as cited and never cause a FAIL: a price in a table row whose seller cell is a link to the offer page; a price range in the text that restates those table rows; figures computed by the answer itself (kWh, yearly cost); the plugin's own reference files cited by file name without a URL.
Formatting does not matter: only substance decides.
