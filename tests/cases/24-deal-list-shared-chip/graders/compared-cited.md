PASS if every price shown in a Compared line (or equivalent comparison list) carries its own `[n]`, and each `[n]` has its own entry in the Sources list naming one page. FAIL if a compared price has no `[n]`, or if a Sources entry groups several pages (for example "pages read by sub-agents, examples: ...").
Formatting does not matter: only substance decides.
