# PC Hardware Advisor

PC Hardware Advisor は、デスクトップPCのハードウェアについて Claude の回答を確かなものにするプラグインです（Claude Code、および Claude デスクトップアプリの Cowork で利用できます）。世界中から部品の最安の配送込み価格を探し、部品同士が一緒に動くかを確認し、用途と予算に合わせて完成構成を設計し、ローカルAI向けのマシン規模を見積もり、中古品の出品を判定し、スケジュールに従って価格を監視します。提示するすべての数値には日付と情報源が付き、確からしさの等級も示されます。このプラグインは読み取りのみを行い、何かを購入することも、販売者に連絡することもありません。

Claude は、あなたが入力した言語で回答します。部品名、SKU、単位は公表されたままの表記を維持します。

## 機能

スキル7つとサブエージェント1つ。

- **`hunt-prices`**: 1つの正確な製品について、世界中から配送込み価格（VAT、関税、送料を含む）が最も安いものを探します。直販店を先に示し、マーケットプレイスは別に一覧にします。各行には確からしさの列があります。複数のサイトを並行して読むため `price-scout` エージェントを使います。
- **`check-compatibility`**: 部品同士の組み合わせごとに判定を出します: 互換、条件付きで互換、非互換。条件付きの判定では、その正確な条件と情報源を示します。
- **`build-config`**: 用途、予算、国、そしてあなたの制約から完成構成を設計します。メイン構成に加え、より安価な版とより高性能な版を返します。提案するのは新品と、整備済み（プロ用に再整備された）品のみです。
- **`size-local-ai`**: モデルをローカルで動かすためのハードウェア規模を見積もります。VRAM、メモリ帯域、トークン毎秒の推定値（推定と明記）、マルチGPU、APU、eGPU、ソフトウェアスタックを扱います。
- **`review-used-listing`**: 中古品の出品を1件審査し、判定を返します: 買う、交渉する、見送る。販売者への質問、受け渡し時に行うテスト、交渉の余地も添えます。
- **`track-price`**: 価格の定期再チェックを設定し、しきい値を下回った時だけ通知し、履歴ファイルを保存します。購入はしません。
- **`find-deals`**: 新品または整備済みパーツについて、あなたが持ってきたセール情報を判定します。今日ほかの販売店より本当に安いか、購入は安全かを確認します。安全でないオファーは割引率にかかわらず除外します。グラフィックカードでは価格履歴を参考情報として添えます。
- **`price-scout`**（エージェント）: 1つの正確な部品について、複数の販売店またはマーケットプレイスのページを読み、正規化された価格行を分析なしで返します。`hunt-prices` がこれを起動します。

対象外: ゲーム機、スマートフォン、タブレット、製品としてのノートPC、そして購入や販売者への連絡を行うもの。

## 原則

- **すべての価格に日付を付けます。** 読み取り日のない価格は報告しません。
- **販売者の種別を明記します。** 直販店、マーケットプレイスの販売者、整備業者、個人は別々の行とし、混ぜることはありません。
- **配送込み価格、または「手数料を除く」。** 価格にはVAT、関税、あなたの国までの送料が含まれます。構成要素を確認できない場合は、推測せず「手数料を除く」と行に記します。
- **確からしさを示します。** 各数値について、どの程度裏付けがあるかを示します。
- **何も捏造しません。** スペック、価格、ルールの情報源を示せない場合、Claude はその旨を伝えます。
- **ブロックされたサイト: ブラウザでの代替読み取り。回避はしません。** サイトが自動読み取りを拒否し、ブラウザツールが利用可能な場合、Claude は一行でブラウザでそのページを開くかどうか尋ねます。「はい」と返信すると、重要な数ページを読み取り専用で読み、その旨を伝えます。キャプチャやボット判定に遭遇したら停止し、人間を装って突破することは決してありません。それ以外の場合は、スクリーンショットまたは貼り付けたテキストを求めます。代替のユーザーエージェント、キャッシュ、ミラーは使用しません。
- **読み取り専用。** このプラグインは購入せず、アカウントを作成せず、フォームを送信せず、販売者に連絡しません。それらはあなた自身が行ってください。

共有リファレンス10件（調査手法、国別の販売店、販売店の基準、海外からの購入、中古市場のチェックリスト、ソケットとチップセット、メモリ、電源ユニットとコネクタ、フォームファクタとケース、AI向けGPU帯域）は、日付と情報源が付いています。最終確認日は 2026-11-07 です。

## インストール

### Claude Code

このリポジトリをマーケットプレイスとして追加し、そこからプラグインをインストールします。

```
claude plugin marketplace add <owner/repo または ローカルパス>
claude plugin install pc-hardware-advisor@pc-hardware-advisor
```

`marketplace add` は、GitHubリポジトリ（`owner/repo`）、git またはhttps の URL、ローカルパスを受け付けます。このリポジトリの GitHub アドレスは `brissonjo-sudo/pc-hardware-advisor` です。ユーザー全体へのインストール（既定は `user`）を望まない場合は、どちらのコマンドにも `--scope project` または `--scope local` を付けてください。

インストール済みのものは `claude plugin marketplace list` で確認できます。

### ローカル開発

インストールせずに作業コピーからプラグインを試す場合:

```
claude --plugin-dir <このリポジトリのパス>
```

### Claude デスクトップ / Cowork

`pc-hardware-advisor.plugin` ファイルを取得します（リリースが公開されている場合はリリースに添付されています。そうでなければ、作業コピーから `python scripts/build_plugin.py` で作成でき、`dist/` に出力されます）。それを Claude デスクトップアプリにドラッグし、インストールの確認に同意してください。

### OpenAI Codex(試験的)

このリポジトリは Codex のマーケットプレイスでもあります(`.agents/plugins/marketplace.json`、マニフェスト `.codex-plugin/plugin.json`)。追加してから、ChatGPT デスクトップアプリまたは Codex(`/plugins`)のプラグインディレクトリからプラグインをインストールしてください。

```
codex plugin marketplace add brissonjo-sudo/pc-hardware-advisor
```

まだテストしていません。Codex にはサブエージェントがないため、価格ページは1ページずつ読まれ、時間がかかります。定期的な価格追跡には、セッション内にスケジューラーツールが必要です。リポジトリは非公開のため、このコマンドにはリポジトリへの git アクセスが必要です。

## 更新、確認、アンインストール

**更新（Claude Code）。** マーケットプレイスを更新し、次にプラグインを更新して、Claude Code を再起動します。

```
claude plugin marketplace update pc-hardware-advisor
claude plugin update pc-hardware-advisor@pc-hardware-advisor
```

更新が提案されるのは、`plugin.json` の `version` が変わったときだけです。

**確認。** Claude に「PC ハードウェア向けのプラグイン skill は何がありますか？」と尋ねるか、`claude plugin list` を実行して `pc-hardware-advisor` とそのバージョンを探します。

**アンインストール。** `claude plugin uninstall pc-hardware-advisor@pc-hardware-advisor` を実行します。Claude デスクトップアプリでは、プラグイン設定から削除します。作成した価格履歴ファイルは、保存した場所にそのまま残ります。

このリポジトリは現在非公開のため、マーケットプレイス経由はアクセス権のあるアカウントでのみ動作します。代わりに `.plugin` ファイルを使えます。

## リクエストの例

Claude は依頼内容から適切なスキルを選びます。例をいくつか挙げます:

1. 「Ryzen 7 9800X3D をドイツへ配送込みで最安で探して。まず直販店、マーケットプレイスは別に。」
2. 「RTX 5070 Ti を米国からカナダへ輸入する方が、関税と送料を含めても安いですか？」
3. 「この DDR5-6000 キットは、ASUS TUF B650 マザーボードと Ryzen 7 7700 で動きますか？組み合わせごとに判定してください。」
4. 「スペインで1,400ユーロの静かな1440pゲーミングPCを組んでください。より安い版とより高性能な版も出してください。」
5. 「70Bモデルをローカルで実用的な速度で動かしたいです。必要なVRAMとメモリ帯域は？中古の24GB GPU 2枚で足りますか？」
6. 「この中古 RTX 3090 の出品（下のリンク）を見てください。買う、交渉する、見送る、どれですか？販売者に何を聞くべきですか？」
7. 「英国の Samsung 990 Pro 2TB の価格を監視して、120ポンドを下回った時だけ知らせてください。」
8. フランス語: 「Trouve-moi le meilleur prix livré en France pour une alimentation 850 W ATX 3.1, vendeurs directs d'abord, places de marché à part.」
9. スペイン語: 「Quiero montar un PC para edición de vídeo con 1.800 EUR en España. ¿Qué configuración me recomiendas, y qué compatibilidad debo vigilar entre placa, RAM y GPU?」
10. 「64GBの統合メモリを持つAPUで32Bモデルは動きますか？どのくらいの速度を見込めますか？推定値はその旨を明記してください。」

## コネクタ

スキルはツールを製品名ではなくカテゴリ（Web検索、Webフェッチ、価格比較ツール、中古品の掲示板サイト、ブラウザ、スケジューラー、通知）で参照するため、同等の機能を持つツールならどれでも使えます。このプラグインはアカウント、APIキー、有料サービスを一切必要としません。カテゴリ、任意のデータソース、すべてのツールに適用されるルールは [CONNECTORS.md](../CONNECTORS.md) にあります。

## 制限事項

- **価格は時間とともに変わります。** 価格が有効なのは読み取り日時点のみです。在庫やプロモーションは数時間で変わります。
- **自動読み取りを拒否するサイトがあります。** その行はブロック済みと表示され、Claude はスクリーンショットまたは貼り付けたテキストを求めます。
- **税率と関税のルールは変動します。** VAT、関税、少額免税の基準は2025年と2026年に何度も変わりました。大きな輸入の前には公式情報源を確認してください。
- **推定値は推定にすぎません。** トークン毎秒やそれに類する予測はモデルによる計算であり、あなたのマシンで計測したものではありません。その旨を明記しています。
- **調査範囲には穴があります。** 一部の国、販売店、ニッチな部品は情報が薄いです。どこが薄いかはリファレンスに記載しています。
- **高いエフォートを使用してください。** メンテナーのテストでは、中程度のエフォートの `build-config` は読む販売店が少なく、より安い選択肢を見逃しました。構成や価格調査を依頼する前に、アプリで高いエフォートを選択してください。
- **金融または法律の助言ではありません。** このプラグインは購入判断の材料を提供するものです。税、関税、消費者法について助言するものではありません。

## プライバシー

プラグイン自体は何も収集せず、どこにも送信しません。`track-price` が書き込む価格履歴は、あなたが保存先に選んだ場所に残ります。Claude が検索とページ読み取りに使うツール（Web検索、Webフェッチ、スケジューラー）は、それぞれの提供元の利用規約とプライバシーポリシーに従います。
